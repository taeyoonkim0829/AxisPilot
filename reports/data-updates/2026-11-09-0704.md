# 인터페이스 코드 채우기 (치수 비교)

## 비교 방법
- 모터·감속기: STEP 도면에서 플랜지 프레임 기준으로 파일럿 Ø, 볼트 원, 축 Ø와 길이를 측정 (파일 576개)
- 코드 기준값: 같은 코드의 Festo 키트 STEP에서 `motorFace` 기준으로 파일럿 구멍, 볼트 원, 허브 구멍과 허브 끝 위치를 측정
- 세 치수(파일럿, 볼트 원, 축 Ø)가 모두 같을 때만 입력. 측정이 안 된 1FK2는 S210 매뉴얼 13.1 치수로 확인

## 빈칸 현황
| 종류 | 전체 | 이전 | 이후 |
|---|---|---|---|
| 축 | 83 | 0 | 0 |
| 연결키트 | 1376 | 0 | 0 |
| 모터 (단종 제외) | 922 | 378 | 224 |
| 감속기 (단종 PA 제외) | 516 | 368 | 232 |

## 입력한 코드 (290개)
| 코드 | 파일럿 / 볼트 원 / 축 | 제품 | 개수 |
|---|---|---|---|
| 130M1 | 110 / 145 / Ø24 | HG-SR51 등, APM-E·F Ø24 | 42 |
| 176M1 | 114.3 / 200 / Ø35 | HG-SR, HG-JR, 1FL6090~096 | 32 |
| 84AA | 80 / 100 / Ø19 | HK-KT 90□, HK-RT103~203, 1FK2205 | 48 |
| 92RA | 80 / 100 / Ø16 | HG-JR 90□ | 20 |
| 126AA | 110 / 130 / Ø24 | 1FK2106 (매뉴얼의 1FK2□06, Festo 표의 1FK2206과 같은 도면) | 12 |
| 50GA | 35 / 44 / Ø12 | AE050 | 21 |
| 70GA | 52 / 62 / Ø16 | AE070 | 21 |
| 90GA | 68 / 80 / Ø22 | AE090, AER090 | 21 |
| 120GC | 90 / 108 / Ø32 | AE120 | 21 |
| 90G0 | 80 / 100 / Ø22 | ABR090 | 26 |
| 115G0 | 110 / 130 / Ø32 | ABR115 | 26 |

- 92RA 선택 이유: 90R도 플랜지와 구멍이 같지만 허브가 34 mm에서 끝나 HG-JR의 40 mm 축에 짧습니다. 92RA 허브는 39 mm까지입니다.
- 84AA와 SA 키트 90A는 측정 치수가 같습니다. 표준 키트가 많은 84AA(축 코드 22종)를 넣었기 때문에, 이 모터들에는 SA 키트 `EAMM-A-T46-90A-SA…`가 뜨지 않습니다.
- AE·ABR의 도면 없는 단수는 같은 크기의 코드를 따랐습니다(출력부가 같다고 보고 입력). 이 항목은 직접 측정한 것이 아닙니다.

## 맞는 코드가 없어 비워 둔 것
- 1FK2208 (130 / 165 / Ø32), 1FK2210 (180 / 215 / Ø38)
- APM-E·F: 130□ Ø19, 180□ Ø42, 220□ 전부, APM-EC04A·APMC-FCL04A·FCL03D (70 / 90 / Ø14)
- HG-JR353·503 (Ø28), HK-KT13UW (Ø8), HK-KT23UW·43UW (Ø14), HK-ST7M2UW·172UW (Ø24), AE155

## 판단이 필요해 비워 둔 것
- **1FL6052·054:** 95 / 115 / Ø19로 100A와 같지만 축이 45 mm입니다. 100A 키트 허브 구멍은 40 mm에서 끝납니다.
- **AB142:** 후보 140G0에 측정할 키트 도면이 없습니다.
- **도면 없음:** ABR042·060, ABR142·180·220, AB180·220, AB060A·090A, AEB090, APMC-FBL03A (48V), 일부 브레이크 모델

## 건드리지 않은 것
- 감속기 입력 쪽 `driveCode`와 `compatibleMotors`: 어떤 모터를 어떤 감속기에 다는지는 이번 작업 범위가 아닙니다.
- 기존에 코드가 있던 제품의 값

## 확인
- 테스트 206개 통과, 15개 건너뜀. 린트 통과
- 조합 15종(모터·감속기별)의 조립 STEP 생성 성공. 조립 결과의 3D 읽기와 간섭 검사는 하지 않았습니다.
- 축과 코드의 대응만 맞춘 것으로, 키트 커플링의 실제 체결 여부는 Festo 확인을 권합니다.
